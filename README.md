💪 GMAX: Gym Membership & Payment Manager

Digital tool I built for GMAX Fitness (Korba) to replace paper records. It manages member registrations and payments and keeps the client database clean and reliable.

This public version uses sample data only. No real member information is included.

🎯 Problem

The gym tracked memberships and payments by hand, which caused lost records, duplicates and slow lookups at the front desk.

✨ Features
Register new members and store their details
Record payments and see who is up to date or overdue
Search and filter members quickly
Data integrity checks to avoid duplicates and wrong entries
